# visual-banjo

## Algorithms

When implementing or modifying an algorithm, include sources in the docstring of the relevant function. Each algorithm should have:
- A plain-English description of what it does
- A primary reference (original paper or standard)
- An accessible link (Wikipedia, tutorial, or freely available text) for building intuition

Keep `algorithms.md` up to date whenever an algorithm is added or changed. That document is the single place to understand what algorithms the software uses and why.
